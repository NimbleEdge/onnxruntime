To build onnx runtime run this command in onnxruntime home directory:
```
python3 tools/ci_build/github/apple/build_and_assemble_apple_pods.py --staging-dir /Users/user/Desktop  --include_ops_by_config < path to produced required_operators_and_types.config file> --build-settings-file tools/ci_build/github/apple/default_full_apple_framework_build_settings.json
```

--include-ops-by-config is the Build option to reduce build to required operator kernels,
required_operators_and_types.config is the file generated by models. This is optional.


to generated `required_operators_and_types.config` file from ml models:

```
python3 tools/python/create_reduced_build_config.py <model_path_or_dir> [Path to write configuration file to.]
```
